# CasCão — Padrões de Projeto GoF

Avaliação Trimestral da matéria de Engenharia de Software demonstrando três padrões GoF:

- Criacional: Builder
- Estrutural: Adapter
- Comportamental: Observer

## Contexto

O CasCão é uma plataforma para intermediação entre tutores de cães e DogWalkers. O exemplo usa cadastro/configuração de DogWalkers, cálculo de distância por um serviço externo e notificações de contratação.

## Execução

Requisito: Java 17+

## Estrutura

- `src/main/java/.../builder`: Builder
- `src/main/java/.../adapter`: Adapter
- `src/main/java/.../observer`: Observer
- `src/main/java/.../Main.java`: demonstração dos três padrões
- `docs/`: diagramas PlantUML
